# Requirements

- Nodejs v22.19+ & npm v10.9.3+
- python3 (for graph generation)
- Intel lab dataset ([link](https://db.csail.mit.edu/labdata/labdata.html]))

# Installation

- Run `npm i`
- Extract intel lab data archive
- (Optional) Adjust the values of `src/config.json` if you rename the extracted file or if you want a different count of iterations

# Running

- Run `npm run start`
- (Optional) Run `python3 plot.py` to generate graph figures
